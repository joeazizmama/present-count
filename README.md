# Present Count 🌐✨

An ultra-sleek, minimalist interactive presence counter and anonymous secret vault web application.

## Features

- **Real-Time Presence Tracking**: Live visitor presence heartbeats and interactive counter.
- **Anonymous Secret Portal**: Leave anonymous ephemeral confessions and explore secrets shared by others.
- **Minimalist Luxury Aesthetic**: Glassmorphism, smooth micro-animations, typography, and dark-mode styling.
- **Persistent Data Store**: Lightweight JSON-backed persistence for presence and vault storage.

## Tech Stack

- **Backend**: Node.js & Express
- **Frontend**: Vanilla HTML5, CSS3 (Custom Glassmorphism Design System), Modern JavaScript
- **Persistence**: File-backed JSON store

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16+ recommended)
- npm

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/joeazizmama/present-count.git
   cd present-count
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the server:
   ```bash
   npm start
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
